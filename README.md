# Click Odyssey

Развивающаяся браузерная ZPG по GDD v0.1 для компьютера и телефона. Игру можно запустить без установки зависимостей; публикация создаёт статическую сборку.

Игра: https://pavel-voronin.github.io/odyssey/ · https://odyssey.kolpaque.dev

Исходники: https://github.com/pavel-voronin/odyssey. Push в main автоматически собирает и публикует игру на GitHub Pages. Workflow использует Node.js 24 без установки зависимостей. Локальные отчёты, сборки и временные инструменты исключены из репозитория.

## Запуск

Установите Node.js 20 или новее. В папке проекта выполните:

```sh
node server.mjs
```

Откройте http://localhost:4173. Для телефона в той же сети используйте IP компьютера и порт 4173. Другой порт задаётся переменной окружения PORT.

## Как играть

Клик по любой части основного игрового экрана или пробел продвигают мир ровно на один тик. В верхней половине — игровой вид, в нижней — дневник. Удерживание пробела не ускоряет время. «Герой / мир» открывает сведения поверх сцены, не меняя симуляцию. Герой самостоятельно выбирает маршруты, обещания, снаряжение, лечение и отступление. После смерти клики и автоматическое время продолжают мир. Новая история начинается только отдельной явной кнопкой.

Прогресс автоматически сохраняется в localStorage браузера, включая состояние генераторов случайных чисел. Текущий единый формат — version2/schema `click-odyssey/144`, без конвертации прежних версий; несовместимая граница этапа144 была разрешена владельцем проекта. Повреждённый или старый импорт получает отказ и не заменяет активный мир. Перезагрузка продолжает ту же историю. Меню позволяет скачать полное сохранение JSON и загрузить его на другом устройстве; после загрузки можно вернуть предыдущее сохранение. «Скачать хронику» экспортирует текст последних событий и последствий; это не резервная копия игрового сохранения. «Новый мир» удаляет текущий прогресс после подтверждения. Звук выключен по умолчанию.

## Возможности

- Связный граф одномерных дорог, деревень, лесов, лагерей и руин; новые области появляются при исследовании развилок.
- Детерминированная симуляция с индивидуальными чертами героя, потребностями, приоритетами и планами из нескольких действий.
- Жители предлагают устранить конкретных волков или собрать существующие травы. Герой возвращается к заказчику за наградой.
- Автоматические пошаговые бои, оценка угроз, зелья, травы, отступление, бесплатный отдых и помощь лекаря.
- Опыт, уровни, три улучшения оружия, броня, находки и торговля. Торговец переезжает, когда появляются другие поселения.
- Память мест, знакомых, слухов и опасностей; журнал объясняет решения и их последствия.
- Убитые противники не возрождаются; собранные вещи исчезают. Мир, могилы и изменения остаются после смерти героя.
- Адаптивная рисованная Canvas-сцена, смена времени суток только по тикам, короткие анимации действий, необязательный звук.
- 12 профессий, 9 предназначений, 12 привычек, 12 рас с внешностью и особенностями, родословные героев и жителей, наследники и истории вещей.
- Психология, суеверия и монетка; голод, болезни и проклятия; заклинания с маной, обучением и восстановлением; мирные работы и жизни без убийств.
- 16 типов мест, настоящие развилки, континенты, подземные города, корабли и острова, порталы и миры сновидений. Переходы требуют времени, иногда денег или работы в команде.
- Эпохи — постоянные области мира. Победа или находка в прошлом меняют настоящее; временные дубликаты создают парадоксы. Основной тик остаётся монотонным.
- Центр управления включает и отключает доменные механики, показывает их конкретные контракты, точки взаимодействия и владение данными. Состояние выключенной механики сохраняется.

## Проверка

```sh
node --test
```

Проверки покрывают воспроизводимость, точность тиков, продолжение сохранения, автономный полный цикл, постоянство мира, смерть, новую жизнь, движение торговца, выключение механик, родословные, мирные жизни, магию, все биомы, морские переходы и временные последствия. `node scripts/simulate.mjs` дополнительно сравнивает парные истории и вмешательства в жизнь; пишет отчёт в `artifacts/simulation-report.json`.

## Устройство

`engine.js` — цикл симуляции, её состояние целиком сериализуемо. Доменные реализации находятся в `modules/`, реестр и независимые RNG-потоки — в `rules.js`, каталоги — в `content.js`. `scene.js` — отрисовка и короткая интерполяция действий; анимация не двигает игровое время. `app.js` — интерфейс, ввод и сохранение. `server.mjs` — локальный сервер на стандартной библиотеке Node.js.

Разработка продолжается. Квесты, отношения, экономика, слухи, мировые события и политическая власть расширяются отдельными этапами; это не завершённая версия. Для игры не требуются внешние шрифты или библиотеки. Нативные мобильные пакеты пока не создаются.

## Публикация

Адрес игры: https://odyssey.kolpaque.dev. После каждого завершённого этапа:

```sh
node scripts/deploy.mjs
```

Нужен доступ к `ssh agent` и установленный `scp`. Скрипт запускает тесты, создаёт статическую сборку с именами ресурсов по хешу содержимого, публикует в `/srv/kolpaque/releases/odyssey/<revision>` и атомарно переключает `/srv/kolpaque/sites/odyssey`. Он использует существующий Caddy wildcard-маршрут без изменения конфигурации сервера. Проверка HTTP и контрольных сумм ресурсов выполняется через публичный HTTPS-адрес; при ошибке внешней проверки восстанавливается предыдущая ссылка, если она была.

Номер сборки отображается в меню. Для получения нового этапа обновите страницу на телефоне; прогресс остаётся в браузере на том же домене. Между устройствами сохранение не синхронизируется. В сборку входят только HTML, CSS, игровые модули и манифест релиза; тесты, инструкции, инструменты публикации и локальные артефакты на сервер не отправляются.
