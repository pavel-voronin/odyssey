# Покрытие исходных пожеланий дизайном

Сверка 14 октября 2026, D-018: выполнена по прямому вопросу пользователя, а не по отсутствию новых входящих. Читается имплементатором/дизайнером, пользователю не открывать. TASKS остаётся единственной очередью; WISHLIST — фактическими требованиями и статусами.

«База» здесь — ссылка на уже описанное/проверенное в WISHLIST, не новый аудит реализации и не подтверждение полного выполнения. ID карточки означает описанный ближайший результат; широкий пункт не закрыт навсегда. При разделении карточки оставшийся объём сохранять явно; следующую частичку продумывать до её взятия. Рабочий UI и технические правила не перепроектировать без выявленной проблемы. Длинный параллакс и backend не разрешены к внедрению этой сверкой.

До сверки недостаточно определены: независимые от знания героя общественные события/поставки, личный репертуар и общий темп редкостей, мировые условия/масштабный кризис, остаток поз врагов/питомцев, долговременный размер истории. Переданы B-01/B-02/B-03/V-05/T-01. Частично общие R-01/R-02/R-03/R-08/R-09/V-04 дополнены конкретными последующими решениями. Это прежние требования, не придуманное увеличение объёма.
